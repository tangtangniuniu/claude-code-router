方式一：直接跑刚才构建好的产物（最快验证）                                                                                                                                                  
                                                                                                                                                                                              
  # 1. 先准备一份最小配置                                                                                                                                                                     
  mkdir -p ~/.claude-code-router
  cat > ~/.claude-code-router/config.json <<'EOF'                                                                                                                                             
  {                                                               
    "APIKEY": "test-key",
    "PROXY_URL": "http://127.0.0.1:7890",
    "Providers": [
      {
        "name": "deepseek",
        "api_base_url": "https://api.deepseek.com/chat/completions",
        "api_key": "sk-你的key",
        "models": ["deepseek-chat"],
        "proxy": false
      }
    ],
    "Router": {
      "default": "deepseek,deepseek-chat"
    }
  }
  EOF

  # 2. 启动服务
  node dist/cli.js start

  # 3. 另开一个终端，打开 Web UI（默认 http://127.0.0.1:3456/ui/）
  node dist/cli.js ui

  # 4. 用 Claude Code 跑一条请求
  node dist/cli.js code

  方式二：把 ccr 命令安装到 PATH

  # 在仓库根目录
  npm link              # 或: pnpm link --global

  # 然后任意目录都能用
  ccr start
  ccr ui
  ccr status
  ccr stop

  方式三：开发模式（改 UI 实时热更新，验证你刚加的代理控件用这个）

  # 终端 1：起 server
  pnpm dev:server

  # 终端 2：起 UI（vite 热更新，默认 5173）
  pnpm dev:ui

  然后浏览器开 http://127.0.0.1:5173，登录用 config.json 里的 APIKEY，进 Providers → 编辑/新增 就能看到新的代理控件（状态徽标 + 卡片 + Switch 开关）。

  ---
  验证你的改动是否生效的简短自测：
  - 不填 proxy → 徽标显示「继承全局」灰色，请求会走 PROXY_URL
  - 填 http://127.0.0.1:7890 → 徽标变绿「自定义代理」
  - 打开 Switch → 徽标变琥珀色「直连（忽略代理）」，输入框灰掉
  - 在调试日志里（LOG_LEVEL=debug）useProxy 字段会反映这次实际生效的代理 URL 或 undefined
